# 슬라이드 코드

이 디렉터리는 강의 슬라이드에 등장하는 주요 코드 블록을 실행 가능한 형태로 정리한 보조 자료입니다.

슬라이드에서는 지면 제약 때문에 `import`, `class`, `main` 메서드, 보조 타입 등이 생략될 수 있습니다.  
이 디렉터리의 코드는 슬라이드의 핵심 코드가 어떤 형태로 실행되는지 확인할 수 있을 만큼만 필요한 내용을 보완합니다.

각 파일 또는 하위 디렉터리는 독립된 예시입니다.  
같은 학습용 이름(`User`, `BankAccount`, `OrderStatus` 등)이 여러 디렉터리에 반복될 수 있으므로 전체 `slide-code/` 디렉터리를 한 번에 컴파일하기보다 필요한 파일이나 디렉터리를 선택해 확인하는 것을 권장합니다.

일부 예시는 컴파일되지 않는 코드나 실행 중 예외를 설명하기 위해 해당 코드를 주석으로 남기거나 예외가 발생하도록 구성되어 있습니다.

장 전체의 개념을 하나의 흐름으로 묶은 통합 예제는 [`../../example-code`](../../example-code)를 참고합니다.
